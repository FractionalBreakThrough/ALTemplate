Step 1

Site Survey

Walk the building with your signal tester. Map every door, identify lock types needed, place gateways, and validate 900MHz coverage. This step prevents 90% of deployment issues.

What You'll Do

  • Walk every door and record prep type, thickness, handing, and fire rating
  • Identify which doors get wireless locks vs. hardwired NA panels
  • Place temporary gateway(s) and test signal strength at every lock position
  • Mark expander positions for any dead zones
  • Verify network connectivity (Wi-Fi SSID or Ethernet drop) for gateway backhaul

What You'll Need

Signal tester
Floor plans
Tape measure
Door schedule form

Pro Tips

Test signal with doors closed — open doors give false-good readings. Metal fire doors attenuate 900MHz significantly.

Place gateways above the ceiling grid when possible — fewer obstructions for the 900MHz signal.

Photograph every door prep during survey — saves a return trip when ordering hardware.

Budget one gateway per floor for standard drywall buildings. Add one expander per floor for concrete/CMU.

Step 2

Hardware Install

Mount the locks and gateways. Wireless locks replace existing mechanical hardware using standard ANSI door prep — no new holes, no frame modification. Gateways mount on a wall or ceiling.

Wireless Locks

  • Remove existing mechanical lock from door
  • Install Trilogy/ArchiTech lock into the same 2-1/8" cross-bore
  • Insert 4 AA batteries — lock powers on
  • Verify latch engagement and handing — adjust strike if needed

Gateways

  • Mount gateway at the location validated during site survey
  • Connect PoE Ethernet cable or plug into power + join Wi-Fi
  • Wait for solid green LED — gateway is online and connected to MVP

NA Panels (if applicable)

  • Mount panel in closet or above ceiling
  • Wire reader, mag-lock/strike, REX, door contact, and fire alarm input
  • Connect PoE or 12VDC power — panel comes online in MVP

Time Estimates

Wireless lock swap
~15 min
Gateway mount + connect
~10 min
NA panel wire + mount
~45 min

Tools Required

Phillips screwdriver Level Wire strippers Drill (if needed) 4 AA batteries

Step 3

Scan2Enroll

This is the magic step. Every Trilogy Networx lock and NA panel ships with a QR code. Scan it with the MVP app — the device is provisioned, named, and connected to the cloud in under 10 seconds. No IP addresses. No MAC entry. No firewall rules.

How It Works

A

Open MVP App

Log into your MVP dealer account on your phone or tablet.

B

Tap "Add Device"

Camera opens — point at the QR code on the lock or panel.

C

Name & Assign

Give the door a name ("Main Lobby," "Suite 200") and assign it to an access group.

D

Device Is Live

Lock connects to the nearest gateway, downloads its credential table, and begins accepting authorized users immediately.

Why This Matters

10 Seconds Per Device

Traditional access control panels require IP assignment, subnet config, MAC registration, and firewall rules. Scan2Enroll does it all with one QR scan.

No IT Department Required

The installer doesn't need network credentials, DHCP reservations, or switch port configurations. The gateway handles backhaul.

Encrypted From Day One

QR enrollment establishes an encrypted tunnel between the device and MVP cloud — TLS from the first handshake.

Step 4

Configure & Commission

All devices are enrolled — now set up the access logic. Create user groups, assign schedules, configure lockdown behavior, and issue credentials. Everything happens in the MVP cloud dashboard from any browser.

Configuration Checklist

  • Create access groups — "All Doors," "Suite 200 Only," "After-Hours Staff"
  • Set schedules — business hours auto-unlock, after-hours lock, holiday calendar
  • Issue credentials — assign cards, PINs, or mobile credentials to each user
  • Configure lockdown — designate who can trigger and which doors participate
  • Set up notifications — door-forced, door-held, low-battery, tamper alerts
  • Test every door — present credential, verify unlock, check audit log in MVP

Hand-Off To Client

  • Create client admin account in MVP
  • Walk client through dashboard — adding users, pulling reports, running lockdown
  • Confirm recurring MVP subscription is active

Launch Day Checklist

All locks respond to test credential
Schedules fire at correct times
Lockdown engages all designated doors
Door-forced alerts trigger in dashboard
Client admin can add/remove users
MVP subscription confirmed active

System Is Live!

Client is operational. Ongoing management happens in MVP — browser-based, from anywhere.
