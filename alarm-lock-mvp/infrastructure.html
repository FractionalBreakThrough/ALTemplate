The Bridge To The Cloud

900MHz Gateways

Gateways bridge the 900MHz wireless locks to the MVP cloud. Each gateway covers up to 64 locks within a 900-foot radius. Choose Wi-Fi or hardwired PoE based on your site.

AL-IM3-80211

Wi-Fi Gateway

Connects to the building's existing Wi-Fi network — no Ethernet run required. Ideal for retrofit projects, distributed buildings, and locations where pulling cable isn't practical.

  • 802.11 b/g/n — connects to any standard Wi-Fi network
  • Up to 64 locks per gateway
  • 900ft range — 900MHz penetrates walls and floors
  • Wall or ceiling mount — compact form factor
  • Plug-in power adapter — standard outlet

Best For

Retrofit sites, multi-building campuses, and locations where Ethernet isn't available near the lock cluster.

Recommended

AL-IM3-POE

PoE Gateway

Hardwired Ethernet with PoE power — one cable for data and power. The most reliable option for new construction, IDF closets, and IT-managed environments.

  • PoE (802.3af) — one cable, no outlet needed
  • Up to 64 locks per gateway
  • 900ft range — same 900MHz radio
  • No Wi-Fi dependency — dedicated wired connection
  • UPS protected — PoE switch on battery = gateway stays up

Best For

New construction, IT-managed buildings, and any site where uptime and reliability are paramount.

How Gateway Coverage Works

Place Gateway Centrally

Mount in a closet, ceiling, or wall — centered among the locks it will serve. 900MHz signal covers ~900ft radius through walls.

Locks Auto-Discover

Trilogy Networx locks find the nearest gateway automatically. No manual frequency programming or channel assignment.

Cloud Connected

Gateway relays credentials, events, and lockdown commands between locks and MVP — encrypted, real-time, bidirectional.

Extended Coverage

Need More Range? Add Expanders.

For large campuses, multi-story buildings, or structures with heavy concrete, 900MHz signal expanders extend the gateway's reach without adding another internet connection.

900MHz Repeater

Receives the gateway signal and rebroadcasts it. Each expander adds another ~900ft of reach in the chain.

Mesh Topology

Expanders form a mesh — if one path is blocked, traffic routes through an alternate expander. Self-healing coverage.

Plug-and-Play

Power it on, it finds the gateway. No IP configuration, no channel programming, no IT involvement.

What Users Carry

Credentials & Keyfobs

MVP supports a wide range of credential technologies. Match the right form factor and protocol to your user population.

HID Prox Cards & Clamshells

125kHz proximity

The most widely deployed access credential in the industry. If your building already has HID Prox cards, Trilogy Networx and ArchiTech N95 locks read them natively — no re-badging.

  • ISO card, clamshell, and keyfob form factors
  • Compatible with all major brand readers
  • 26-bit Wiegand standard format
  • Photo-ID printable ISO cards available

HID Prox Cards

MIFARE & DESFire

13.56MHz smart cards

Higher-security encrypted credentials for facilities that require mutual authentication between card and reader. Prevents cloning and replay attacks that 125kHz prox is vulnerable to.

  • AES-128 encrypted communication
  • Clone-proof mutual authentication
  • Multi-application (access + vending + parking)
  • Required by GSA, DoD, and FICAM standards

MIFARE DESFire Cards

Keyfobs

Compact proximity tokens

For users who don't want to carry a card — keyfobs clip to a keychain and present at the reader like a standard card. Available in HID Prox, iClass, and multi-tech formats.

  • Keychain-sized — fits with car keys
  • Durable polycarbonate shell
  • Same credential format as cards — interchangeable
  • Popular for multi-family & residential tenants

Proximity Keyfobs

Mobile Credentials

BLE / NFC phone-based access

Turn authorized smartphones into access credentials. Users unlock via Bluetooth proximity or NFC tap — no physical card to lose, issue, or replace. Provisioned through MVP cloud, revoked instantly.

  • iOS and Android support
  • BLE proximity + NFC tap modes
  • Zero credential cost — no cards to purchase
  • Instant issuance & revocation from MVP

Before You Install

Site Survey & Planning Tools

A successful wireless deployment starts with a site survey. These tools help you validate 900MHz coverage, plan gateway placement, and identify potential dead zones before a single lock goes on a door.

900MHz Signal Tester

Handheld tool that measures received signal strength from a gateway. Walk the building and map coverage zones — green/yellow/red readings at every door location.

Pro tip: Test at peak hours with doors closed. Metal fire doors and elevator shafts are the most common signal blockers.

Coverage Planning Worksheet

Floor-plan template for plotting gateway locations, lock positions, and expander placements. Mark distances and wall types to estimate signal attenuation before testing.

Rule of thumb: One gateway per floor for standard drywall construction. Add expanders for concrete/CMU buildings.

Door Schedule Audit

Checklist for each door: prep type, door thickness, handing, existing hardware, frame material, fire rating, and ADA compliance. Determines which Trilogy or NA-panel product fits each opening.
