Patented Design

Why "Pick-Proof" Isn't Marketing.

Standard deadbolt cylinders can be defeated in under 60 seconds by a locksmith with a pick set — or by an intruder with a $10 bump-key kit. Marks USA engineers the cylinder differently.

  • Anti-Pick Side-Bar Mechanism

    Spring-loaded side bar prevents conventional picking tools from setting the pins — a lockpicker's signature attack is defeated.

  • Anti-Bump Pin Stack

    Security pins with modified geometry prevent bump-key attacks. No kinetic transfer, no bypass.

  • Hardened Drill Plate

    Case-hardened steel inserts resist drilling attacks against the cylinder housing and the deadbolt throw.

  • Restricted Keyway

    Patented keyway profile — blanks aren't available at big-box stores. Key duplication controlled by the property manager.

IBC Section 1010.1.9

Single-Motion Egress, Every Time.

Life-safety code requires that occupants be able to exit through any commercial door with a single motion — no secondary unlatching, no thumb-turn, no fumbling in an emergency.

Marks USA Behavior

Turn the interior lever → deadbolt retracts → latch retracts → door opens. All in one continuous motion.

Typical Smart Deadbolt

Turn thumb-turn to retract deadbolt → turn interior knob to retract latch → door opens. Two motions = code violation on commercial doors.

How Users Pair Their Phone

MVP sends an enrollment invite. The user accepts, pairs, and unlocks — in under a minute. Click each step to follow the flow.

1

Invite

Property Manager Invites User

From MVP, the manager enters the tenant's email and assigns door access. MVP generates a secure enrollment link.

2

Install

User Installs MobileLink App

The tenant gets an email, installs MobileLink (iOS/Android), and taps the enrollment link — the app opens and logs them in.

3

Pair

Phone Pairs via BLE

Tenant approaches the door — MobileLink handshakes with the Marks USA lock over Bluetooth Low Energy. Encrypted credential is written to the lock.

4

Unlock

Proximity Unlock

From now on, tenant approaches the door with the phone in pocket and taps the lever or MobileLink button — door unlocks instantly.

Step 1 of 4

Instant Revocation

Tenant moves out? Pull the credential in one click.

When the property manager deactivates a user in MVP, the credential is revoked on the lock at next sync — typically within seconds. No lock change, no rekey, no lost keys.
