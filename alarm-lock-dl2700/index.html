Alarm Lock DL2700

Trilogy Keyless Digital Lock

Standalone access control with PIN-based entry. No wiring, no network required. Ideal for commercial doors, offices, and restricted areas.

Key Features

🔒

Keyless Entry

PIN-code access eliminates the need for keys. Supports up to 100 unique user codes.

🔔

Audible Alerts

Built-in buzzer provides feedback for valid entry, invalid attempts, and low-battery warnings.

🔋

Battery Powered

Runs on 5 AA batteries with approximately 80,000 cycles per set. No wiring needed.

Standard door prep. Replaces most cylindrical locksets without additional drilling.

Quick Programming Guide

1

Enter Programming Mode

Press ⚙ (the Alarm Lock button), then enter the master code (default: 1 2 3 4 5 6), then press ⚙ again.

2

Add a User Code

Press 1, enter the new user code (3-6 digits), then press ⚙ to confirm.

3

Delete a User Code

Press 2, enter the code to delete, then press ⚙ to confirm removal.

4

Exit Programming

Press ⚙ to exit programming mode. The lock returns to normal operation.

Always change the default master code after installation. Refer to the full manual for advanced scheduling and lockout features.
