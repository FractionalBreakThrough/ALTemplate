# ALTemplate - Web Design Project

## Project Overview
Single-page landing page for GuidedOps - an access control and security platform guided adoption service.

## Tech Stack
- Pure HTML/CSS/JavaScript (no frameworks, no build tools)
- Single `index.html` file with inline styles and scripts
- Dark theme with blue/gold accents

## Design Guidelines
- Follow the web-design skill for all UI work (`/web-design`)
- Use design tokens from `.claude/skills/web-design/design-tokens.md`
- Mobile-first responsive design
- WCAG 2.1 AA accessibility compliance

## Graphics
- When Nanobanana MCP is available, use it for generating custom images
- Set `GEMINI_API_KEY` environment variable to enable image generation
- Prefer CSS effects and SVG for decorative elements when possible

## Deployment
- Static hosting (no server required)
- All assets should be inline or referenced via CDN
